# twothirds.studio

The TwoThirds Studio website, served by GitHub Pages at https://twothirds.studio.

- `/` studio home
- `/trashley/` Trashley's page
- `/trashley/privacy/` Trashley's privacy policy (linked from the app and the Play listing)

Plain HTML and one stylesheet: no build step, no scripts, nothing loaded from other sites.
The font is Bricolage Grotesque, under the SIL Open Font License (`assets/fonts/OFL.txt`).
